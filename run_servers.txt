# Commands to Run the DASS Assignment Servers

To run the application, you will need to open two separate terminal windows (or tabs) and run the backend and frontend simultaneously.

## Terminal 1: Start the Backend Server
1. Navigate to the backend directory:
   cd backend

2. Install dependencies (if you haven't already):
   npm install

3. Start the server (using nodemon for auto-reloading during development):
   npm run dev

   (Alternatively, if you don't want auto-reloading, you can run: node server.js)


## Terminal 2: Start the Frontend Validation Server
1. Navigate to the frontend directory:
   cd frontend

2. Install dependencies (if you haven't already):
   npm install

3. Start the Vite development server:
   npm run dev

Once both servers are running, the frontend will typically be accessible at http://localhost:5173, and it will communicate with your backend running on port 5000.
