1. Core Infrastructure
Frontend: React (via Vite)

Why: Fast setup, standard industry choice, better performance than Create-React-App.

Backend: Node.js + Express.js

Why: Mandatory for the assignment. Handles API routing and middleware efficiently.

Database: MongoDB Atlas (Cloud)

Why: Mandatory. Access from anywhere (Render/Vercel) without IP blocking issues.

ODM: Mongoose

Why: Enforces schemas (data safety) and handles relationships (populate) easily.

2. Frontend Libraries (/frontend)
Styling: Tailwind CSS + DaisyUI

Why: Speed. Pre-built components (Cards, Navbars, Modals) mean you write 80% less CSS.

Routing: react-router-dom

Why: Standard routing for Single Page Applications (SPA).

HTTP Client: axios

Why: Easier syntax than fetch(), handles JSON automatically.

State/Auth: Context API (Built-in)

Why: Redux is overkill. Context is perfect for storing the "User" object.

QR Scanning: react-qr-reader

Why: Native React component. Much easier to integrate than raw JS libraries.

Real-time: socket.io-client

Why: Connects to the backend for the "Discussion Forum".

Notifications: react-hot-toast

Why: Beautiful "Success/Error" popups with one line of code.

Icons: react-icons

Why: Access to every icon set (FontAwesome, Material, etc.) in one package.

3. Backend Libraries (/backend)
Authentication: jsonwebtoken (JWT) + bcryptjs

Why: Secure stateless sessions; hashing passwords effectively.

File Uploads: multer + cloudinary

Why: Crucial simplification. Stores images in the cloud and saves a short URL in Mongo. Prevents "Payload Too Large" database errors.

Real-time: socket.io

Why: Handles the WebSocket connections for the Forum.

QR Generation: qrcode

Why: Generates the "Ticket" QR code image string on the server side.

Email: nodemailer

Why: Sends the actual "Ticket Confirmation" emails using a standard Gmail account.

Utilities: cors, dotenv

Why: Security and configuration management.

4. Deployment & Tools
Frontend Host: Vercel

Backend Host: Render (Web Service)

Dev Tool: nodemon (Restart server automatically)
